## 2. ★ 클라이맥스 — 최종보스전 (교과서 41쪽 11번)

> **문제 원문**: 원 x² + y² = 8 위의 점 A와 직선 y = x + 6 위의 서로 다른 두 점 B, C를 꼭짓점으로 하는 정삼각형 ABC를 만들 때, 그 넓이의 최댓값과 최솟값을 구하시오.

코드를 고도화할 때 아래 3단계 흐름을 반드시 유지한다. 각 페이즈가 풀이의 한 단계와 1:1로 대응한다.

| 페이즈 | 플레이어 행동 (카드) | 수학적 의미 | 연출 |
|---|---|---|---|
| **Phase 1** 기준선 고정 | [직선의 일반형 x − y + 6 = 0] | y = x + 6을 일반형으로 변환 | 캔버스 레이저 궤도를 긋고 보스 기믹 고정 |
| **Phase 2** 철갑 파쇄 (Armor Break) | [점과 직선 사이의 거리 d] → [한계 일도양단 (d ± r)] (3층 중간보스 전리품) | 원의 중심 O에서 직선까지 d = 6/√2 = 3√2, r = 2√2 → 정삼각형 높이 h의 범위 d − r = √2 ≤ h ≤ d + r = 5√2 | 흑백 만화톤 집중선 반전, 주인공 푸른 안광 컷인, 대각선 X자 참격 → 8각 철갑 파편 물리 낙하, 심장(코어) 노출 |
| **Phase 3** 5초 QTE 피니시 | [정삼각형 넓이 공식 S = h²/√3] (상점 무료 유산 카드, 덱의 조커) | h² = 2 → S = 2√3/3 (최솟값) · h² = 50 → S = 50√3/3 (최댓값) | 슬로모션 + 5초 카운트다운, 심장 박동음. 정답 세트를 골라야 섬멸 |

### 검산 (Claude 확인)

- 높이 h인 정삼각형: 한 변 a = 2h/√3 → S = (√3/4)·a² = (√3/4)·(4h²/3) = **h²/√3 = √3h²/3** ✅
- 최솟값 h = √2 → S = 2/√3 = **2√3/3** ✅
- 최댓값 h = 5√2 → S = 50/√3 = **50√3/3** ✅

### 소프트 리트라이 (Soft Retry)

- 오답 또는 시간 초과 시 **게임오버 없음**.
- 카세트테이프 되감기 글리치 + Rewind 사운드와 함께 **3초 전(심장 노출 직전)** 으로 즉시 되감기 → 스트레스 없이 재도전.
- 교육적 의도: 기초가 부족한 학생도 실패 비용 없이 반복 시도하게 해서, 정답에 도달하는 경험을 보장한다.

### 메모

- 교과서상 11번은 **발전** 난이도이며 `서술형` 표기는 06번, 09번에 붙어 있다. 게임 안에서 "서술형 보스"라고 부르는 것은 풀이 과정을 단계별 카드로 서술한다는 의미로 쓴 연출 명칭이다.

| 층 | 교과서 단원 | 합성 레시피 | 보스 / 기믹 |
|---|---|---|---|
| 1층 | 수직선과 평면좌표 (12~17쪽) | [점 A] + [빼기(−)] + [점 B] → [선분의 길이 \|x₂ − x₁\|] · [가로/세로 선분] + [루트] → [평면 거리 공식] | 수직선 수문장 골렘 / 트라이앵글 무게중심 엘리트 |
| 2층 | 직선의 위치 관계 (18~22쪽) | [한 점 (x₁, y₁)] + [빼기(−)] + [기울기 m] → [직선의 방정식] | 방패 거수 (수직 조건 mm′ = −1 공략) |
| 3층 | 점과 직선 사이의 거리 & 원 (23~41쪽) | [직선 일반형] + [점의 좌표] + [분모 부품] → [점과 직선 사이의 거리 d] | 중간보스 (41쪽 07번) 격파 → 전리품 [한계 일도양단 (d ± r)] |
| 최종 | 41쪽 11번 | 위 테크트리 완성품 총집결 | 정삼각형 결계 + QTE + 소프트 리트라이 |

- 3층 중간보스 07번 검산: 원 (x − 2)² + (y − 5)² = 4, 직선 3x − 4y − 6 = 0 → d = |6 − 20 − 6|/5 = 4, r = 2 → **최댓값 6, 최솟값 2**. 이 문제가 [d ± r] 카드의 출처라 최종보스 Phase 2와 자연스럽게 연결된다.
- 층별 쪽수 범위는 Gemini 브리핑 기준이다. 스테이지를 구현할 때 교과서 소단원 경계와 다시 맞춰 볼 것.

## 6. 구현 현황 (v0.2.1)

### 핵심 규칙: 몬스터 = 문제

- 몬스터는 문제 하나를 갖고 등장한다. 전투 중에는 문제가 바뀌지 않고, 쓰러지거나 후퇴했다 돌아와도 같은 문제다.
- 문제는 풀이 단계로 나뉘고, 단계마다 체력 **문턱**이 있다. 공격·크리티컬·옵션은 문턱을 넘지 못한다. **풀이만 문턱을 깬다.**
- 맞는 풀이 카드를 문턱에서 내면 그 단계의 4지선다가 나온다. 맞히면 문턱이 깨지고 **영구 패널티**와 피해가 들어간다. 틀리면 해설이 나오고 단계는 그대로 남는다.

### 문제 스캔 (v0.2.1)

- 문제 문장은 **조각**으로 나뉜다. 첫 조각은 무료로 보이고, 나머지는 `???`. 문제 그림도 공개된 조각만큼만 그려진다.
- **스캔 카드**(🔍)를 내면 조각이 하나씩 공개된다 (공격·방어와 함께 적용).
- 단계마다 필요한 조각 수가 있다. 조각이 부족하면 풀이 카드는 맞든 틀리든 "아직 문제를 다 파악하지 못했다"는 같은 메시지만 나오고, 기력은 들지 않으며 카드도 손에 남는다.

| 몬스터 | HP · 문턱 | 조각 | 단계 (필요 조각) → 영구 패널티 |
|---|---|---|---|
| 수직선 슬라임 (1층 잡몹) | 30 · [15] | 2 | [선분의 길이] (2) → 약점 노출 ×1.5 |
| 골렘 (1층 보스) | 70 · [46, 23] | 3 | [내분점] P(3, 6) (2) → 철갑 파괴 / [두 점 사이 거리] 3√5 (3) → 핵 노출 |
| 결계 박쥐 (2층 잡몹) | 40 · [20] | 3 | [평행 조건] (3) → 결계 소멸 |
| 방패 거수 (2층 보스) | 80 · [52, 26] | 3 | [수직 조건] 기울기 2 (2) → 방패 파괴 / [직선의 방정식] y = 2x − 3 (3) → 심장 노출 |
| 차원 군주 (체험판) | 120 · [100, 82, 64, 36, 12, 12] | 4 | 6단계 (2, 2, 2, 3, 4, QTE 4) |

검산 (v0.2와 같음, 숫자 변경 없음): 골렘 P = ((2·5 + 1·(−1))/3, (2·8 + 1·2)/3) = (3, 6), OP = √(3² + 6²) = √45 = 3√5. 거수 (−½)·m′ = −1 → m′ = 2, y + 1 = 2(x − 1) → y = 2x − 3. (`tests/game.test.js`에서 독립 검산)

### 전투 규칙 (v0.2.1)

| 상황 | 결과 |
|---|---|
| 문턱 전 | 모든 카드(풀이 카드 포함)가 공격·방어·스캔으로 작동 |
| 문턱 + 맞는 풀이 카드 + 조각 충분 | 4지선다 → 정답이면 단계 해결 |
| 문턱 + 풀이 카드 + 조각 부족 | 같은 안내 메시지, 기력 소모 없음, 카드는 손에 남음 |
| 문턱 + 맞지 않는 카드 | 기력 −1, 공격은 튕김, 방어·스캔은 적용, 카드는 버림 더미로 |
| 📌 홀드 (기력 1) | 고른 카드 1장이 턴 종료 한 번을 버티고 손에 남음 |
| ⚡ 긴급 연성 (기력 1, 턴당 1번) | 숙련된 레시피만, 손패 카드를 바쳐 임시 카드 생성. 전투가 끝나면 임시 카드는 사라지고 바친 카드는 돌아옴(전투는 덱 복사본) |
| 막힘 안전장치 | 문턱에서 3턴 진행이 없으면 필요한 조각 공개 + 풀이 카드 지급(이 전투만) |
| ⛺ 후퇴 | 직전 캠프로. 같은 문제, 몬스터 체력은 처음부터 |
| 쓰러짐 | 되감기 연출 후 "같은 덱으로 재도전" / "캠프로 되감기(덱 수정)" |

### 카드 (v0.2.1)

- 모든 카드에 ⚔공격 🛡방어 수치가 있다. **합계 = 투자 점수 + 2 ~ + 4** (자연수, 분배는 무작위). 투자 점수 = 소재 수 + 연성 횟수 × 2. 연성할 때마다 새로 굴린다.
- 매직은 옵션 1개(디아블로식, 11종), 레어 2개, 유니크는 고정 설계. 크리티컬: 매직 10% ×1.5, 레어 15% ×1.5, 유니크 25% ×2.
- 스캔: 차이 카드는 항상, 일반 카드는 35% 확률, 매직은 없음.

| 등급 | 카드 | 투자 점수 | 공+방 | 만드는 법 |
|---|---|---|---|---|
| 기본 | 차이 x₂ − x₁ (🔍항상) | 4 | 6~8 | [x₁] − [x₂] (순서 무관) |
| 일반 | 선분의 길이 \|x₂ − x₁\| (풀이 도구) | 6 | 8~10 | \|·\| [차이] |
| 일반 | 차이² (x₂ − x₁)² | 6 | 8~10 | [차이]² 또는 [선분의 길이]² |
| 부품 | 제곱의 합 | — | — | [차이²] + [⇄차이²] |
| 부품 | 기울기 m | — | — | [⇄차이(세로)] ÷ [차이(가로)] (순서 중요) |
| 매직 | 내분점 | 4 | 6~8 | [x₁] m : n [x₂] |
| 매직 | 두 점 사이의 거리 | 16 | 18~20 | √ [제곱의 합] |
| 매직 | 평행 조건 m = m′ | 12 | 14~16 | [기울기] = [m′] |
| 매직 | 수직 조건 mm′ = −1 | 12 | 14~16 | [기울기] × [m′] |
| 매직 | 직선의 방정식 | 13 | 15~17 | [한 점] − [기울기] |

- m′은 2층부터 무한 제공되는 부품. 기울기와 × 또는 = 에만 반응한다.
- 연립 연산은 잠금 표시("V0.4에서 열림").
- 체험판 전용: 원의 방정식·점과 직선 사이의 거리(레어), 한계 일도양단(유니크, 공격 30, 관통·치명 +25%·분쇄 15%), 정삼각형 넓이(특수).

### 캠프: 대장간 · 덱 구성

- 모루: `[재료] [연산] [재료]` 또는 `[연산] [재료]`. 재료 = 부품 가방 + 보관함 카드(잠긴 카드 제외). **재료로 쓴 카드는 사라진다.**
- 차이·선분의 길이·차이² 카드는 모루 위에서 **⇄ 축 바꾸기**.
- 같은 카드를 직접 3번 연성하면 **숙련** → ⚡ 즉시 연성 + 전투 중 긴급 연성 가능.
- 틀린 조합은 재료를 돌려주고 개념 피드백을 준다 (세로 ÷ 가로 순서, 축을 안 바꾼 제곱 합, 두 좌표 더하기 = 중점 등).
- 덱 구성 탭: 보관함 ↔ 덱 이동, 🔒 잠금, 분해(소재 절반 회수). 덱 규칙 **6~12장 · 스캔 4장 이상(차이 1장 이상) · 매직 4장 이하**. 규칙을 어기면 출발 불가.
- 캠프에는 층의 단원 범위만 표시한다.
- 시작 카드: 랜덤 수치 차이 카드 6장. 부품: 캠프 1에서 x₁·x₂ 6개씩, 슬라임 4개씩, 골렘 6개씩 + 한 점 2개, 박쥐 4개씩 + 한 점 1개. 분해하면 점은 x₁·x₂ 반씩, 남는 1개는 가방에 적은 쪽(`Craft.refundParts`).

### ² · √ 발견형 연산 (v0.3.2)

| 연산 | 처음 | 발견 조건 | 막힘 방지 (자동 해금) |
|---|---|---|---|
| ² | 🔒 (누르면 "같은 것을 두 번 곱해 보면…?") | 같은 것끼리 × 를 **시도** (레시피가 없어도). [차이] × [차이] → 차이² 레시피도 있음. 가로 × 세로는 "넓이" 안내만 | 2층 첫 캠프 |
| √ | 🔒 | ² 발견 후 ² 를 모루에 올렸다가 **눌러서 꺼내기** (다른 연산으로 바꾸거나 연성 후 비워질 때는 안 셈) | 1층 골렘 입장 (골렘 ② 단계가 두 점 사이의 거리를 요구) |

- 1층 분산: 첫 캠프 튜토리얼 끝에 ² 발견 유도(선택) → 슬라임 보상에서 ² 를 못 찾았으면 차이(가로) 카드 2장 + 힌트(`nudge`) → 골렘 직전 캠프에서 ²·√ 단계별 안내(`guide`) → 골렘 입장 √ 자동 해금(`autoOps`).
- [제곱의 합] 안내는 √ 상태에 따라 다르다: 잠김이면 "² 를 올렸다가 꺼내 보자", 발견 후면 "√를 씌워야 두 점 사이의 거리!". 점과 직선 거리 레시피에는 √ 힌트를 주지 않는다.
- 발견한 연산은 저장(`unlocked`)되고 되감기·이어하기 후에도 유지. 기록이 없는 옛 저장은 골렘을 지났으면 둘 다 해금.
- **레어 규칙**: 이름별 1장, 재료로 써도 보관함·손패에 남음, 다시 연성하면 기존/새 카드 중 선택 (`forge.js` addCard).
- **전투 중 각성**: 단계의 `forge.from` 레어 중 하나는 손에, 나머지는 덱에 있으면 유니크 연성 (`battle.js` ensureTool). 07번 승리 시 `dPlusR` 레시피 해금(도감 발견 목록에 기록).
- **적 디버프 의도**: `intents[].debuff = { vuln | weak: 턴 }`. 플레이어 취약 = 받는 피해 ×1.5, 약화 = 카드 공격 ×0.75 (풀이 피해는 그대로). 적 행동 뒤 1턴씩 줄어든다.

### 연성창 정리 (v0.2.2)

- 캠프 대장간 순서: 범위(한 줄) → 탭 → 안내(한 줄) → **연산**(기호 위주, 폰 5개씩 2줄) → **부품**(x₁, x₂, 한 점, m′…) → **모루**(화면 위 고정) → **보관함 묶음** → 레시피 도감.
- 보관함 묶음: 종류별 한 칸(×장수, 덱 장수, 세로 장수), 순서 고정(`STACK_ORDER`). 누르면 덱 밖 → 수치 낮은 카드가 모루로, ▾로 펼치면 한 줄 목록에서 직접 선택. 덱 구성 탭은 낱장.
- 폰·패드: 재료·카드는 탭으로만 올리고(`touch-action: manipulation`, 터치 시작을 막지 않음), 손가락을 움직이면 스크롤. 마우스는 끌어다 놓기도 됨.
- **첫 연성 튜토리얼:** 캠페인 첫 캠프에서 한 번(`G.tutorial`이 없을 때). 어두운 화면에 구멍을 내 x₁ → − → x₂ → 연성 순서로 안내하고, 구멍 밖은 눌리지 않는다. 건너뛰기 가능, 결과는 저장과 결과 보내기에 기록.

| 페이즈 | 단계 | 도구 (기억 복원으로 지급) | 정답 |
|---|---|---|---|
| 1 기준선 고정 | ① | 직선의 방정식 (매직) | x − y + 6 = 0 → 보스 공격 −2 |
| 2 수선의 발 측정 | ② | 원의 방정식 (레어) | 중심 (0, 0), 반지름 2√2 |
| | ③ | 점과 직선 사이의 거리 (레어) | d = 6/√2 = 3√2 |
| | ④ | 한계 일도양단 (유니크, **전투 중 연성**) | √2 ≤ h ≤ 5√2 → 만화 컷인 + ARMOR BREAK |
| 3 심장 타격 | ⑤ | 정삼각형 넓이 (특수) | S = h²/√3 → 슬로모션 |
| | ⑥ | 5초 QTE | 최솟값 2√3/3 · 최댓값 50√3/3 → 섬멸. 오답·시간 초과면 3초 전으로 되감기 후 재도전 |

- 시작 덱: 랜덤 수치 차이 카드 9장. 단계마다 필요한 카드를 "기억 복원" 연출로 손에 쥐여 준다.
- QTE는 4조각이 모두 필요하며, QTE 단계에 들어가면 남은 조각이 자동 공개된다.
- ④에서 레어 두 장이 합쳐져 유니크가 연성된다. 레어는 사라지지 않는다.

### 검증 (v0.2.1)

- `node tests/mathgen.test.js`, `node tests/game.test.js` 통과 (연성 규칙 14개, 수치 범위·옵션 4000회, 스캔 확률, 덱 규칙, 몬스터 조각·필요 조각, 보스 정답).
- Playwright 자동 플레이: 캠페인(PC·모바일)·체험판 클리어, 콘솔 오류 0. 덱 규칙 위반 출발 거부, 잠금·분해, 쓰러짐 → 캠프 되감기 / 재도전, 홀드 유지, 긴급 연성(손패 → 임시 카드), 조각 부족 시 기력 미소모, 문턱에서 맞지 않는 카드(기력 −1·피해 0), 후퇴(취소·실행), 안전장치 발동을 확인.
- 세이브: 단위 테스트(무작위 문제 300회 재생성 일치, 저장 → 불러오기 왕복, 다른 버전 거부)와 브라우저 테스트(PC·모바일). 캠프·전투 중·보상 화면에서 새로고침 → 이어하기, 같은 문제 유지, 새로 시작 확인 창, 저장소 차단 환경에서 진행 가능.
