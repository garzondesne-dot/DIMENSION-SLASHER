## 수업 흐름

| 페이즈 | 내용 | 몬스터 | 자물쇠 |
|---|---|---|---|
| 1 · 집합의 기억 (전시학습, 2차시) | 연성: 소속 판정 `[원소] ∈ [집합]`, 원소의 개수 `n( )[집합]` | 소속 슬라임 · 공집합 유령 | m1 · m2 |
| 2 ① 부분집합 (3차시 STEP 1·2) | 연성: 부분집합 `[A] ⊂ [B]` | 유닛 골렘 · 포함의 기사 | m3 · m4 |
| 2 ② 같은 집합 (3차시 STEP 3·4) | 연성: 서로 같은 집합 `[A ⊂ B] 이고 [B ⊂ A]`, 진부분집합 `[A ⊂ B] 이고 [B ⊄ A]` | 거울 쌍둥이 · 부분집합 수집가 | m5 · m6 |
| 3 · 형성평가 필드 (혼자) | 연성: 2ⁿ `[2] ^ [n]`, 2ⁿ⁻ᵖ, 2ⁿ⁻q, 2ⁿ⁻ᵖ⁻q | 기호 집게 · 개수 도깨비불 · 미지수 기사 · **중간보스 2ⁿ의 수호자** | p3 (한 번에 전부) |

- **연성 = 예제**: 카드를 처음 만들 때 한 번, 모루가 반짝이며 예제가 뜬다. 맞혀야 완성, 틀리면 재료를 돌려받고 숫자가 바뀐 예제로 다시.
- **엄격한 연성**: ∈ · ⊂ · ⊄ · 거듭제곱 · 빼기는 왼쪽·오른쪽 순서를 지켜야 한다. 틀리면 개념 메시지("∈ 의 왼쪽은 원소, 오른쪽은 집합", "1 ⊂ {1, 4} ✕" 등).
- **문제 형식**: 기호 넣기(□ 여러 칸), O/X, 숫자 패드, 여러 개 고르기, 부분집합 모두 만들기(원소를 눌러 집합을 만들고 추가).
- **막히지 않게**: 덱은 자동(새 카드 자동 투입), 결계 보호막에 닿으면 덱의 풀이 카드가 손으로 날아온다. 부분집합·원소의 개수 카드는 재료로 써도 남는다. 처음 캠프·처음 전투마다 안내.
- **문제풀이모드**: 선생님이 학생 폰 ⚙ 설정 → 교사 코드(4자리, 교사용 화면의 보라색 줄)를 넣으면 모든 카드 + 체력이 1 아래로 안 떨어짐. 자물쇠는 그대로. 진행 배지와 결과에 "문제풀이모드" 표시.
- **진행 배지**: 화면 위쪽에 페이즈 · 몬스터 ■□ · "몬스터 3/10 · 연성 4/9".
- **실시간 현황 (2차)**: 사건 기록(`DS.Track`)을 몇 초마다 결과 시트 '진행' 탭으로 보내고, 교사용 `sets/dashboard.html` 이 학생 × 몬스터 표와 도움이 필요한 학생을 보여 준다. 설정·운영: [sets-dashboard.md](sets-dashboard.md)

## 해금 코드
- 날짜 + 자물쇠 이름의 해시(`sets/js/codes.js`). 날마다 바뀌고 어제 코드도 통과(자정 대비). 몬스터·필드 3자리, 문제풀이모드 4자리.
- 교사용 화면에서 날짜를 골라 미리 확인·인쇄 가능. 줄을 누르면 크게 띄우고(칠판·TV), 다시 누르면 지운 줄로 표시.

## 문제와 검산 (`node sets/tests/game.test.js`)

| 몬스터 | 문제 | 정답 | 독립 검산 |
|---|---|---|---|
| 소속 슬라임 | A = {x \| x는 12의 약수}: 4·8, 12·5·1 □ A | ∈ ∉ / ∈ ∉ ∈ | 12의 약수를 직접 구해 포함 여부 |
| 공집합 유령 | n({x \| x는 1보다 작은 자연수}) + n({0}), {0} 은 공집합? | 1, X | n(∅) = 0, n({0}) = 1 |
| 유닛 골렘 | {1, 5, 25} □ {x \| x는 25의 약수}, {−2, 0, 2} □ {x \| x² − 2x = 0} | ⊂, ⊄ | 약수·근을 직접 계산 ({0, 2}) |
| 포함의 기사 | 옳지 않은 것 모두 (6개 중) / ∅ ⊂ ∅ | 2 ⊂ {1, 2}, {1} ∈ {1, 2} / O | 각 보기를 기호 규칙대로 판정 |
| 거울 쌍둥이 | {x \| 4의 약수} □ {1, 2, 4}, {x \| 8 이하 짝수} □ {2, 4, 6} / A = {1, a + 1} = B = {1, 4} | =, ≠ / a = 3 | 집합 비교, a 대입 |
| 부분집합 수집가 | {1, 2, 3} 의 부분집합 모두 / 진부분집합의 개수 | 8개 / 7 | 부분집합 전부 나열 |
| 기호 집게 | {x \| x² = 1} □ {−1, 1}, {0} □ {0, 1} (∈ ∉ ⊂ ⊄) | =, ⊂ | 근 계산 |
| 개수 도깨비불 | {x \| 6의 약수} 의 진부분집합 / {a, b, c, d, e} 의 부분집합 | 15 / 32 | 부분집합 직접 세기 |
| 미지수 기사 | A = {a, a + 2} ⊂ {1, 2, 3, 4} 인 a 모두 / {1, 3, a} = {1, b, 5} → a + b | 1, 2 / 8 | a 대입, a·b 전수 조사 |
| 중간보스 2ⁿ의 수호자 | A = {x \| 12의 약수} (n = 6): 부분집합 / 1·12 포함 / 홀수 미포함 / 2·4 포함·3 제외 | 64 / 16 / 16 / 8 | 2⁶개 부분집합을 직접 세기 |

연성 예제 24개도 같은 방식으로 검산한다(약수·근·부분집합을 직접 계산).
