# 결정 목록

새 아이디어는 이 목록과 먼저 대조한다. 기존 결정과 부딪히면 반영하기 전에 알린다.
진행 방식: **논의 → 확정안 → "진행"이라고 하면 구현.** 시제품 단계이므로 의견을 바로 코드에 반영하지 않는다.

## ✅ 확정 (v0.2에 구현)

| 영역 | 결정 | 이유 |
|---|---|---|
| 전투 | **몬스터 = 문제.** 카드는 문제를 푸는 도구 | "어떤 공식을 써야 하나"라는 판단이 게임 플레이가 된다. 잡몹부터 최종보스까지 규칙이 하나로 통일됨 |
| 전투 | 전투 중 문제는 고정, 되감기 후에도 같은 문제 | 몬스터 = 문제와 일관. 해설을 본 뒤 다시 풀 기회 |
| 전투 | **체력 문턱**: 공격은 문턱을 못 넘고, 풀이만 문턱을 깬다 | 문제를 안 풀고 공격만으로 이기는 구멍을 막는다. 공격·크리티컬은 문턱 사이에서 의미를 가짐 |
| 전투 | 풀이 단계 성공 → 몬스터에 영구 패널티 | 풀수록 약해지는 게 보임. 골렘의 "철갑 수복" 행동은 이와 충돌해 삭제 |
| 전투 | 맞지 않는 도구: 힌트 + 기력 소모, 카드는 손에 남음 | 찍기(아무 카드나 내 보기)를 막으면서 손해는 작게 |
| 전투 | 화면에 다음 단계의 "목표"는 보여 주되 도구 이름은 숨김 | 목표 → 도구 연결이 학습 목표 |
| 조합 | 카드가 곧 부품인 다단계 조합, 한 번에 연산 하나 | 레시피 나무 = 교과서 유도 과정 |
| 조합 | 선분 카드의 축 바꾸기(x ↔ y) | 가로·세로가 같은 구조임을 체험. 3단원 y = x 대칭의 예고 |
| 조합 | 등급: 일반 → 매직 → 레어 → 유니크 (+ 특수), 등급은 공식마다 정해짐 | 중간 단계((x₂−x₁)² 등)는 등급 없는 부품. "연성 한 번 = 등급 하나" 규칙과의 모순 해소 |
| 조합 | 일반·매직: 재료로 쓰면 사라짐, 장수 제한 없음 | 강화할지 유지할지 고민하는 재미 |
| 조합 | 숙련: 일반·매직 카드를 직접 3번 연성하면 즉시 연성 | 반복 학습 + 지루함 방지 |
| 조합 | 연산은 처음부터 무한 | 재화 관리까지 넣으면 복잡도가 과해짐 (아래 보류 참고) |
| 조합 | 부품은 문제를 푼 보상으로 얻음 | "문제를 풀면 도구가 생긴다" |
| 크리티컬 | 매직 10% ×1.5 / 레어 15% ×1.5 / 유니크 25% ×2, 기본·일반은 없음 | 짜릿함 + 등급을 올릴 이유. 문턱은 크리티컬로도 못 넘음 |
| 개발 | 전투 / 조합 / 조준 세 덩어리 분리, 조준은 `js/challenge.js`에 끼우고 빼는 구조 | 조준 실험이 실패해도 원점 회귀가 쉬움 |
| 개발 | v0.1 태그 보존 | 언제든 돌아갈 기준점 |
