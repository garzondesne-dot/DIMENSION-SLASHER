# 결정 목록

새 아이디어는 이 목록과 먼저 대조한다. 기존 결정과 부딪히면 반영하기 전에 알린다.
진행 방식: **논의 → 확정안 → "진행"이라고 하면 구현.** 시제품 단계이므로 의견을 바로 코드에 반영하지 않는다.

## ✅ 확정 (v0.2.1에 구현)

### 전투: 스캔과 문턱

| 결정 | 이유 |
|---|---|
| 문제는 **조각**으로 나뉘어 처음엔 흐릿하다. 첫 조각은 무료, 나머지는 **스캔 카드**로 공개 | 캠프에서 다음 문제를 미리 알려 주면 "몬스터와 조우해서 문제를 파악한다"는 경험이 사라진다(플레이어 기만). 대신 전투 안에서 문제를 읽는 행동을 게임으로 만듦 |
| 단계마다 필요한 조각 수(needs)가 있다. 조각이 부족하면 풀이 카드는 **맞든 틀리든 같은 메시지**, 기력 소모 없음, 카드는 손에 남음 | 문제를 다 읽지 않고 정답 카드를 떠보는 것을 막는다. 같은 메시지라야 정답 여부가 새지 않음 |
| 문턱 전에는 **모든 카드가 공격·방어(+스캔)**로 작동 (풀이 카드 포함) | 도구 카드도 덱에서 손해가 아니게. 크리티컬이 실제로 터질 기회(매직 카드도 공격) |
| 문턱에서 맞지 않는 카드: **기력 −1, 공격은 튕기고 방어·스캔은 적용**, 카드는 버림 더미 | 찍기에 작은 비용. 방어·스캔은 살려서 손해가 과하지 않게 (사용자 확정 문구 그대로) |
| 문턱 도달 자체는 기력을 쓰지 않음 | 문턱은 벌이 아니라 "이제 풀 차례"라는 신호 |
| **홀드**: 기력 1, 카드 1장을 다음 턴까지 손에 남김 (턴 종료 한 번만 버팀) | 도구 카드가 문턱 직전에 버려지는 불운을 플레이어가 대비할 수 있게 |
| **긴급 연성**: 기력 1, 턴당 1번, **숙련된 레시피만, 손패 카드로만**. 만든 카드는 임시 | 가방의 카드를 전투 중에 꺼내 쓰는 건 덱 구성의 의미를 없앰(어불성설). 숙련 보상으로 의미를 줌 |
| 전투는 덱의 복사본으로 진행 → 긴급 연성에 바친 카드는 전투 후 돌아오고 임시 카드는 사라짐 | 스캔 카드를 재료로 바쳐도 다음 전투에 불이익이 없게 |
| **막힘 안전장치**: 문턱에서 3턴 동안 진행이 없으면 필요한 조각 공개 + 풀이 카드 지급(이 전투만) | 덱을 잘못 짰거나 운이 나빠도 절대 막히지 않게. 학습 부담을 늘리는 페널티를 넣지 않는다는 원칙 |
| **후퇴**: 언제든 직전 캠프로. 다시 오면 같은 문제, 몬스터 체력은 처음부터 | 덱을 다시 짜고 싶을 때의 출구 |
| 쓰러짐: "같은 덱으로 재도전" / "캠프로 되감기(덱 수정)" 중 선택 | 게임오버 대신 되감기. 덱을 고칠지는 학생이 정함 |
| 캠프에는 **층의 단원 범위만** 표시 (다음 몬스터·문제·필요 도구 경고 없음) | 스캔과 같은 이유. 단원 범위는 수업 진도와 연결되므로 공개 |

### 카드: 수치와 옵션

| 결정 | 이유 |
|---|---|
| 기본 베기·막기 **삭제**. 시작 덱 = 랜덤 수치 차이 카드 6장 (체험판 9장) | 모든 카드가 수학 카드. 차이 카드의 평균치가 옛 베기·막기를 대신함 |
| 디아블로식 랜덤 수치: 공격 + 방어 합계 = **투자 점수 + 2 ~ + 4**, 자연수, 분배는 무작위. 투자 점수 = 소재 수 + 연성 횟수 × 2 | 같은 카드도 매번 다르게 나와 연성하는 재미. 많이 투자한 공식일수록 강함 |
| 재료 카드의 수치는 결과에 영향 없음 | 계산을 단순하게, 수치 노가다 방지 |
| 매직 옵션 1개, 레어 2개, 유니크는 고정 설계 | 등급마다 느낌 차이. 유니크는 이름값을 하는 고정 효과 |
| 옵션 11종: 방어막 관통, 치명타 확률, 치명타 피해, 취약, 약화, 출혈, 분쇄, 흡혈, 반격 방어, 행운의 적중, 추가 드로우 | 디아블로 계열 옵션 참고. 어떤 옵션도 문턱은 못 넘음 |
| 크리티컬: 매직 10% ×1.5 / 레어 15% ×1.5 / 유니크 25% ×2, 기본·일반은 없음 | 짜릿함 + 등급을 올릴 이유 |
| 스캔: 차이 카드는 항상, 일반 카드는 35% 확률, 매직은 없음 | 차이 카드가 "상대를 파악하는" 기본 카드. 매직은 풀이 도구라 역할 분리 |
| 차이²는 일반 카드로 남김, 제곱의 합·기울기는 **부품**(덱에 안 들어감) | 중간 단계가 덱을 채우지 않게. 기울기는 소재가 많아 일반 카드로 두면 수치가 어색함 |
| 평행·수직 조건은 매직 (m′은 무한 부품) | m′을 무한 제공하므로 투자 점수가 과하지 않음 |

### 연성

| 결정 | 이유 |
|---|---|
| 빼기는 어느 순서로 넣어도 **x₂ − x₁**으로 정리 | 순서 실수로 막히지 않게. 순서가 중요한 건 기울기(세로 ÷ 가로)에서만 |
| Δx·Δy 같은 별도 부품을 만들지 않음. 차이 카드를 ⇄로 뒤집어 y₂ − y₁ | 교과서 표기 그대로. 부품 종류를 늘리지 않음 |
| 절댓값 연산 추가: \|차이\| → 선분의 길이 | 수직선 위 거리 = \|x₂ − x₁\| (교과서 정의) |
| 내분점 = [x₁] m : n [x₂] | v0.2의 [m : n][선분] 조합은 수학적으로 틀렸음(길이에서는 점이 안 나옴). 사용자 제보로 수정 |
| m′은 무한 부품, 기울기와 × (수직) 또는 = (평행)에만 반응 | 두 번째 기울기를 매번 만들게 하면 지루함. 반응 범위를 좁혀 개념은 유지 |
| **연립** 연산은 보이되 잠김("V0.4에서 열림") | 수직이등분선 = 중점 · 연립 · 수직. 앞으로 열릴 것을 예고 |

### 덱 구성

| 결정 | 이유 |
|---|---|
| 보관함에 모든 카드, 덱은 그중에서 고름 | 연성 결과를 버리지 않고 쌓아 둘 수 있게 |
| 덱 규칙: **6~12장, 스캔 카드 4장 이상(그중 차이 1장 이상), 매직 4장 이하**(같은 매직 중복 허용) | 스캔 없이는 문제를 못 읽음. 매직 상한으로 "모든 도구를 다 챙기기"를 막고 판단을 요구 |
| 잠금: 잠긴 카드는 재료로 못 씀 / 분해: 소재의 절반 회수 | 좋은 수치가 나온 카드를 실수로 녹이지 않게. 나쁜 카드 정리 수단 |
| 덱 규칙을 어기면 출발할 수 없고 덱 구성 탭으로 이동 | 규칙 위반 상태로 전투에 들어가 막히는 일을 막음 |

## ✅ 확정 (v0.2.2에 구현)

| 결정 | 이유 |
|---|---|
| **점 부품을 x₁·x₂로 다시 분리.** [x₁] − [x₂] → 차이(순서 무관, 항상 x₂ − x₁), [x₁] m : n [x₂] → 내분점 | 카드 공식(x₂ − x₁)과 같은 글자를 써야 연결이 보임(사용자 의견). A·B는 v0.1부터 쓰던 이름이었을 뿐 |
| 분해 회수: 점 2개 이상이면 x₁·x₂ 반씩, 남는 1개는 **가방에 적은 쪽**(같으면 랜덤) | 완전 랜덤이면 한쪽만 쌓여 다시 진행이 막힐 수 있음(v0.2.1.1에서 통합했던 이유). 연성은 항상 x₁·x₂를 하나씩 쓰므로 이렇게 돌려주면 개수 차이가 1을 넘지 않음. 테스트로 검증 |
| '한 점 (x₁, y₁)' 부품은 그대로, 점 부품은 y 없이 x₁·x₂ | 교과서 직선의 방정식 표기 유지. 괄호·y 유무로 구별 |

## ✅ 확정 (v0.3.2에 구현) — 연성 개편 (대기 목록 A-1~A-5)

사용자와 논의해 확정한 v0.3 변경점. 사용자 "구현하고 배포해줘"로 v0.3.2에 구현. 바뀐 기존 결정에는 ⚠️ 표시. 세부 구현·검산은 [HANDOVER.md](HANDOVER.md) "3층·4층"과 "² · √ 발견형 연산".

### A-1. 원의 방정식 · 완전제곱 개편 (사용자 스케치)

| 결정 | 이유·비고 |
|---|---|
| 3층 캠프 [원 (일반형)] 부품 → **일반 카드 [x² + y² − 2ax − 2by = 0]** (기력 1, 상수 C 없음) | 카드 공식을 단순하게. 결과는 r² = a² + b² |
| 새 연산 **분해**: 일반 카드 → [x² − 2ax] + [y² − 2by] (1장 → 2조각) | 연성이 아니라 쪼개기부터 시작 (사용자 설계). 구현: 연산 이름 **"✂ 식 분해"**(3층부터) — 덱 구성 탭의 카드 "분해"(소재 회수)와 헷갈리지 않게 |
| 새 **무한 부품 「영(零)의 결정」**: 혼자는 반응 없음, [x² − 2ax] 옆에 올리면 a² − a², [y² − 2by] 옆이면 b² − b² 로 변신 | "0을 더해도 식은 그대로" |
| 결과 조각은 **[(x − a)² − a²]**, **[(y − b)² − b²]** — (x − a)² 만 쓰지 않음 | x² − 2ax = (x − a)² 오개념 방지 |
| 두 조각을 합치면 **레어 원의 방정식** (x − a)² + (y − b)² = r² (r² = a² + b²). 연성 4번으로 일반 → 레어 | "연성 횟수를 늘려 레어답게" 원칙 |
| 기존 레시피 [거리] = [r] → ² 도 유지, 도감에 **"길 2개"** 표시 (한 카드 두 레시피) | 30쪽 원의 정의(중심에서 거리 r)를 잃지 않게. 다회차 요소 후보(💬 논의점) |
| 매직 **완전제곱 카드, [반의 제곱] 부품 삭제**. 가면 원령 ①단계 도구 → 원의 방정식 (목표 문구는 그대로) | 카드 종류를 줄여 캐주얼하게 |
| 가면 원령 문제는 교과서 그대로(33쪽 예제 3), 문제 화면에 상수 힌트 "−3 도 넘기면 r² = 16" | 카드에는 C가 없으므로. 검산: x² + y² + 6x − 4y − 3 = 0 → a = −3, b = 2 → (x + 3)² + (y − 2)² = 9 + 4 + 3 = 16 |
| 0의 변신 연출 4줄: 혼자 올림("짝이 필요해요") → 변신("a² 이 하나만 더 있으면 (x − a)² …! 0 을 a² − a² 로 쪼개 보자") → 결과("빌려 온 a² 은 반드시 빼서 갚는다!") → 합칠 때("빌린 a², b² 을 오른쪽으로 → r²") | 사용자: "스토리나 피드백을 줘야 한다" |
| 실수 메시지: 0 없이 연성 / 분해 직후 바로 합치기("아직 둘 다 완전제곱이 아니에요") / 부호("+6x = −2a·x → a = −3") | |

| 결정 | 이유·비고 |
|---|---|
| ² 는 처음에 🔒(보이되 잠김, 누르면 "같은 것을 두 번 곱해 보면…?") | 숨기면 시도할 계기가 없음. 연립 "보이되 잠김"과 같은 방식 |
| 같은 것끼리 × 를 **시도**하면 영구 해금 (레시피에 없는 조합이어도). 새 레시피: [차이] × [차이] → 차이², [선분의 길이] × [선분의 길이] → 차이² (같은 축) | 제곱 = 같은 것을 두 번 곱하기 (사용자). × 는 카드 2장, ² 는 1장 → 발견이 곧 보상 |
| 가로 × 세로는 해금 아님: "가로 × 세로는 직사각형의 넓이예요. 같은 것끼리 곱해야 제곱!" | 제곱이 아니므로 |
| 해금 연출 "² 제곱 연산을 발견했다! 같은 것을 두 번 곱하는 걸 한 번에." 저장·되감기 후에도 유지 | 타임루프 속에서도 기억은 남는다 |
| 도감·연성 안내는 해금 전 "[차이] × [차이]", 해금 후 "[차이] ²" | |

### A-5. √ 발견형 연산 + 1층 부담 분산

| 결정 | 이유·비고 |
|---|---|
| √ 는 처음에 🔒. ² 해금 후 ² 를 모루에 올렸다가 **눌러서 꺼내면** 영구 해금 (다른 연산으로 바꾸거나 연성 후 자동으로 비워질 때는 안 셈) | 넣었다 빼기 = 되돌리기 = 제곱을 되돌리는 √ (사용자) |
| 해금 연출 "되돌리는 힘을 깨달았다! √ — 3² = 9 이니까 √9 = 3" | |
| 1층 분산: **첫 캠프** 튜토리얼 끝에 ² 발견 유도(선택) → **슬라임 보상**에서 ² 미발견이면 힌트 + 차이(가로) 카드 2장 → **골렘 직전 캠프**에서 √ 발견과 두 점 사이 거리 | 1층 골렘이 두 점 사이 거리(√ 필수)를 요구하므로 한 캠프에 발견이 몰리지 않게 |
| 막힘 방지: 골렘 직전 캠프에서 ² → √ 단계별 안내, √ 는 **골렘 입장 때**, ² 는 **2층 입장 때** 자동 해금. 기존 저장 파일은 둘 다 자동 해금 | 벌 없음 원칙 |

| 저장 코드 내보내기·불러오기 (다른 PC·브라우저로 옮기기) | 학교 PC 초기화 프로그램 환경에서 필요해지면. 지금 세이브는 같은 PC·같은 브라우저에서만 이어짐 |
| **기력 최대 4칸 · 턴마다 3칸 회복**(남은 기력 이월) | 사용자 제안. 아껴 두는 판단이 생겨 덱 구성 싸움이 치밀해짐. 전투 밸런스가 바뀌고 학생에게 설명할 규칙이 늘어나므로 베타 테스트 결과를 본 뒤 결정 |
