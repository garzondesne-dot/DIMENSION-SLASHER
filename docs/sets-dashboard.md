## 처음 한 번: Code.gs 바꾸고 다시 배포 (약 5분, PC 권장)

1. 구글 드라이브의 **`DIMENSION-SLASHER Code.gs (번외편 2차).txt`** 를 연다. (결과 시트 ID와 현황 비밀번호가 미리 채워진 사본. 저장소의 Code.gs 에는 둘 다 비어 있다.)
2. 지금 쓰는 Apps Script 프로젝트(결과 보내기용)를 연다 → `Code.gs` 내용을 **모두 지우고** 1의 내용을 붙여 넣는다 → 💾 저장.
3. **배포 → 배포 관리 → ✏️(연필) → 버전: "새 버전" → 배포**.
   - ⚠ **"새 배포"를 누르면 주소가 바뀌어** 본편·번외편 모두 기록이 안 들어간다. 반드시 "배포 관리"에서 새 버전.
4. 확인: 브라우저에서 `웹앱주소?mode=ping` 을 열어 `{"ok":true,"ver":2}` 가 보이면 끝.
5. 현황 페이지를 열고 비밀번호(TEACHER_KEY)를 넣는다. 학생이 아무도 없으면 "아직 기록이 없어요".

## 현황 페이지 보는 법
- 위쪽 카드: 참여 학생, **⚠ 도움이 필요한 학생**, 평균 공략 몬스터, 🔒 코드 대기 중(자물쇠별), 많이 틀린 몬스터.
- 몬스터 10칸: 몬스터별 공략 인원(막대 = 반 대비 비율).
- 학생 표: 번호 · 지금 위치(⚔ 몬스터 / 🔒 대기 / ⚒ 캠프 / 🏁 클리어) · 몬스터 칸(페이즈별로 띄움) · 연성 수 · 정답률 · **살펴볼 점** · 마지막 신호.
- 빨간 줄(맨 위로 정렬) = 도움이 필요한 학생:
  - 반 중간보다 몬스터 **2마리 이상** 뒤처짐
  - 같은 몬스터 **5분** 넘게
  - 같은 몬스터에서 오답 **3번** 이상
  - **3분** 넘게 신호 없음 (화면 꺼짐·인터넷)
  - → 찾아가서 설명하거나, 학생 폰 ⚙ → 교사 코드로 **문제풀이모드**.
- 10초마다 자동 갱신. 날짜·반을 고를 수 있다(기본: 오늘, 기록이 가장 많은 반).
