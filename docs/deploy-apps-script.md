# 폰으로 여는 배포 웹 만들기 (Google Apps Script)

구글 시트 하나에 Apps Script를 붙여 **게임 페이지 + 결과 수집**을 한 번에 한다.
학생은 웹 앱 주소(또는 QR)만 열면 되고, 로그인은 필요 없다. [📨 결과 보내기]는 같은 시트의 '결과' 탭에 한 줄씩 쌓인다.

> 설정은 **PC에서** 한다 (Apps Script 편집기는 폰에서 쓰기 어렵다). 약 10분.

## 준비물

| 파일 | 어디서 |
|---|---|
| `Code.gs` | 저장소 `deploy/apps-script/Code.gs` |
| `game.html` | 배포용 단독 HTML (`python3 tools/bundle.py game.html`로 만들거나 Claude가 만든 파일) |

## 1. 시트와 스크립트 만들기

1. 구글 드라이브에서 **새 구글 시트**를 만든다 (예: `디멘션 슬래셔 베타`).
2. 메뉴 **확장 프로그램 → Apps Script**.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고 `Code.gs` 파일 내용을 붙여 넣는다.
4. 왼쪽 **파일 옆 + → HTML** → 이름을 `game`으로 입력 (자동으로 `game.html`이 됨).
5. `game.html`의 기본 내용을 모두 지우고, 배포용 `game.html` 파일 내용 **전체**를 붙여 넣는다.
   - PC 메모장에서 파일을 연 뒤 `Ctrl + A` → `Ctrl + C` → 편집기에서 `Ctrl + V`. 약 20만 자라 붙여 넣는 데 몇 초 걸린다.
6. 💾 저장 (`Ctrl + S`).

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴 → **웹 앱** 선택.
3. 설정:
   - 설명: `베타 1차` (아무거나)
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생 로그인 불필요)
4. **배포** → 권한 검토 → 내 계정 선택.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**. 내가 만든 스크립트가 내 시트에 쓰는 권한이다.
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사한다.

## 3. 시험해 보기 (수업 전에 꼭)

1. 내 폰으로 웹 앱 URL을 연다 → 학년·반·번호 입력 → 캠페인 시작 → 튜토리얼 → 캠프에서 [📨 결과 보내기].
2. 시트에 **'결과' 탭**이 생기고 한 줄이 들어왔는지 확인한다.
3. 학교 와이파이에서도 한 번 해 본다 (방화벽 확인).

## 4. 학생에게 나눠 주기

- 웹 앱 URL을 QR 코드로 만들어 칠판·화면에 띄운다 (QR이 필요하면 Claude에게 URL을 주면 만들어 준다).
- 주소가 길어서 메신저로 보낼 때는 링크 단축 서비스를 써도 된다.

## 5. 게임을 새 버전으로 바꿀 때 (주소 유지)

1. `game.html` 내용을 새 파일로 통째로 바꿔 붙여 넣고 저장.
2. **배포 → 배포 관리** → 기존 배포의 ✏️(수정) → 버전: **새 버전** → 배포.
3. 주소는 그대로이고, 학생이 새로고침하면 새 버전이 열린다.
   - "새 배포"를 다시 누르면 주소가 바뀌니 주의.

## 유의 사항

- 받는 개인정보는 학년·반·번호뿐이다. 이름은 받지 않는다.
- 웹 앱 주소를 아는 사람은 누구나 게임을 열고 결과를 보낼 수 있다. 베타 테스트가 끝나면 **배포 관리 → 보관(Archive)**으로 중지한다.
- 반 전체가 동시에 보내도 줄이 섞이지 않게 스크립트가 잠금을 건다.
- 화면 맨 위에 "이 애플리케이션은 Google Apps Script 사용자가 만들었습니다"라는 회색 줄이 보이는 것은 정상이다 (구글이 붙이는 안내).
- 세이브(이어하기)는 기기·브라우저별로 저장된다. 같은 폰, 같은 브라우저로 같은 주소를 열면 이어진다.
- 파일로 여는 판에서도 결과를 받고 싶으면 이 웹 앱 URL을 `js/data.js`의 `DS.REPORT_URL`에 넣는다 (`python3 tools/bundle.py 출력.html <URL>`). 같은 시트의 '결과' 탭으로 들어간다.
