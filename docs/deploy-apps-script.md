# 폰으로 여는 배포 웹 만들기 (Google Apps Script)

> **v0.3부터 게임은 GitHub Pages(https://garzondesne-dot.github.io/DIMENSION-SLASHER/)에서만 관리한다** ([deploy-github-pages.md](deploy-github-pages.md)).
> 이 Apps Script 웹 앱은 **결과 받기**만 맡고, 예전 주소(QR)로 들어온 학생에게는 게임 대신 **[▶ 새 주소에서 게임하기]** 버튼을 보여 준다 (`Code.gs` 맨 위 `NEW_URL`).
> 드라이브에 게임 파일을 다시 올릴 필요가 없다. `NEW_URL = ''`로 비우면 아래 설명대로 드라이브의 게임 파일을 보여 주는 예전 방식으로 돌아간다.
>
> `Code.gs`를 바꾼 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**. "새 배포"는 주소가 바뀌어 결과가 안 들어오니 주의.

구글 시트 하나에 Apps Script를 붙여 **게임 페이지 + 결과 수집**을 한 번에 한다.
학생은 웹 앱 주소(또는 QR)만 열면 되고, 로그인은 필요 없다. [📨 결과 보내기]는 같은 시트의 '결과' 탭에 한 줄씩 쌓인다.

게임 파일은 **구글 드라이브에 올려 두고**, 스크립트가 이름에 `dimension-slasher-game`이 들어간 HTML 중 **가장 최근에 올린 파일**을 찾아 보여 준다.
그래서 폰에서도 설정할 수 있고, 새 버전은 드라이브에 다시 올리기만 하면 된다.

## 준비물

| 파일 | 쓰는 곳 |
|---|---|
| `dimension-slasher-game.html` | 구글 드라이브에 업로드 (`python3 tools/bundle.py dimension-slasher-game.html`로 만들거나 Claude가 만든 파일) |
| `Code.gs` (폰에서는 `Code.gs.txt`) | Apps Script 편집기에 붙여 넣기. 저장소 `deploy/apps-script/Code.gs` |

## 1. 게임 파일을 드라이브에 올리기 (폰)

1. 받은 `dimension-slasher-game.html`을 폰에 저장한다 (메신저·메일 첨부 → 다운로드).
2. **구글 드라이브 앱** → 오른쪽 아래 **+ → 업로드** → 다운로드 폴더에서 파일 선택.
   - 이름 뒤에 `(1)`이 붙어도 괜찮다. 공유 설정은 바꾸지 않아도 된다(스크립트가 내 계정으로 읽음).

## 2. 시트와 스크립트 만들기 (폰 크롬, 데스크톱 모드)

1. **크롬**에서 `sheets.google.com`을 연다 → 오른쪽 위 **⋮ → "데스크톱 사이트" 체크**.
   - 구글 시트 *앱*에는 "확장 프로그램" 메뉴가 없어서 크롬으로 해야 한다.
2. **빈 스프레드시트** 만들기 (이름 예: `디멘션 슬래셔 베타`).
3. 메뉴 **확장 프로그램 → Apps Script** (새 탭이 열림).
4. 편집기의 `Code.gs` 기본 내용(`function myFunction() …`)을 모두 지우고, `Code.gs.txt`의 내용을 붙여 넣는다.
   - 폰에서 `Code.gs.txt`를 열어 길게 눌러 **모두 선택 → 복사**.
5. 💾 **저장** 아이콘.
   - 시트를 거치지 않고 Apps Script를 따로 만들었다면(단독 프로젝트), `Code.gs` 맨 위 `RESULT_SHEET = ''` 따옴표 안에 **결과를 받을 시트의 링크**를 넣는다. 비워 두면 결과 보내기가 "전송하지 못했어요"로 끝난다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. "유형 선택" 옆 톱니바퀴 → **웹 앱**.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생 로그인 불필요)
4. **배포** → **액세스 승인** → 내 계정 선택.
   - "Google에서 확인하지 않은 앱" → **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
   - 승인 화면에 **스프레드시트**와 **Google 드라이브** 권한이 보인다. 스크립트는 이 시트에 결과를 쓰고, 드라이브에서 게임 파일 하나를 읽기만 한다 (코드는 `Code.gs`에 그대로 보임).
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사한다.

## 4. 시험해 보기 (수업 전에 꼭)

1. 웹 앱 URL을 새 탭에서 연다 → 학년·반·번호 입력 → 캠페인 시작 → 튜토리얼 → 캠프에서 [📨 결과 보내기].
2. 시트에 **'결과' 탭**이 생기고 한 줄이 들어왔는지 확인한다.
3. 학교 와이파이에서도 한 번 해 본다 (방화벽 확인).
- "게임 파일을 찾지 못했어요"가 나오면 1번 업로드를 확인한다.
- 결과 보내기가 "전송하지 못했어요"로 끝나면 결과 시트 연결(`RESULT_SHEET`)을 확인한다. Apps Script 왼쪽 **실행** 기록에 오류 메시지가 남는다.

## 5. 학생에게 나눠 주기

- 웹 앱 URL을 QR 코드로 만들어 칠판·화면에 띄운다 (QR이 필요하면 Claude에게 URL을 주면 만들어 준다).

## 6. 게임을 새 버전으로 바꿀 때 (주소 유지, 재배포 필요 없음)

1. 새 `dimension-slasher-game.html`을 드라이브에 **다시 업로드**한다. 가장 최근 파일이 자동으로 쓰인다.
2. 학생은 새로고침만 하면 된다. 예전 파일은 지워도 되고 남겨 둬도 된다.
- 이전 버전으로 돌아가려면 최신 파일을 휴지통으로 옮기면 된다.
- `Code.gs`를 고쳤을 때만 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** (주소 유지). "새 배포"는 주소가 바뀌니 주의.

## PC에서 하는 경우 (붙여 넣기 방식도 가능)

- 위 순서를 PC 크롬에서 그대로 해도 된다 (데스크톱 모드 설정만 필요 없음).
- 드라이브를 쓰지 않으려면 Apps Script 편집기에서 **파일 + → HTML → 이름 `game`**을 만들고 게임 HTML 전체를 붙여 넣는다. 드라이브에 게임 파일이 없을 때 이 `game.html`을 쓴다.
- 특정 파일만 쓰고 싶으면 `Code.gs` 맨 위 `GAME_FILE`에 드라이브 파일 **링크**를 넣는다.

## 유의 사항

- 받는 개인정보는 학년·반·번호뿐이다. 이름은 받지 않는다.
- 웹 앱 주소를 아는 사람은 누구나 게임을 열고 결과를 보낼 수 있다. 베타 테스트가 끝나면 **배포 → 배포 관리 → 보관**으로 중지한다.
- 반 전체가 동시에 보내도 줄이 섞이지 않게 스크립트가 잠금을 건다.
- 화면 맨 위에 "이 애플리케이션은 Google Apps Script 사용자가 만들었습니다"라는 회색 줄이 보이는 것은 정상이다.
- 세이브(이어하기)는 기기·브라우저별로 저장된다. 같은 폰, 같은 브라우저로 같은 주소를 열면 이어진다.
- 드라이브 웹(PC)의 설정 "업로드 파일을 Google 문서 형식으로 변환"이 켜져 있으면 HTML이 문서로 바뀌어 올라갈 수 있다. 그때는 설정을 끄고 다시 올린다.
- 파일로 여는 판에서도 결과를 받고 싶으면 이 웹 앱 URL을 `DS.REPORT_URL`에 넣는다 (`python3 tools/bundle.py 출력.html <URL>`). 같은 시트의 '결과' 탭으로 들어간다.
