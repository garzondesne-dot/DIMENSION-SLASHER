## 새 카드 (차원별 연성)

차원이 바뀌면 지난 차원 카드는 **📜 지난 차원 서고**로 들어가고, 새 차원의 기본 카드 6장을 받는다.
서고의 카드는 [꺼내기]로 이번 차원 보관함에 옮겨 재료·덱에 쓴다. 차원에 들어올 때 다음 차원 레시피에 필요한 카드를 서고에 보급한다.

| 차원 | 카드 | 연성 |
|---|---|---|
| Ⅰ | 점의 평행이동 (매직) | [한 점] + [이동 (a, b)] |
| Ⅰ | 도형의 평행이동 (매직) | [도형 f(x, y) = 0] ↦ [점의 평행이동] |
| Ⅰ | 점의 대칭이동 (매직) | [한 점] ⟷ [대칭의 기준] |
| Ⅰ | 도형의 대칭이동 (매직) | [도형] ↦ [점의 대칭이동] |
| Ⅰ | **원의 방정식 (레어, 바뀜)** | [두 점 사이의 거리] ↦ [한 점(중심)] = [반지름 r] → ² |
| Ⅰ | **점과 직선 사이의 거리 (레어, 바뀜, 기력 2)** | [수직 조건] × [직선] → 수선, 수선 ↦ [한 점] → 수선의 발 H, [두 점 사이의 거리] ↦ [H] |
| Ⅱ | 원소 확인 (기본) · 교집합 · 합집합 · 여집합(⇄ A/B) · 차집합 · 부정(⇄ p/q) | ∈, ∩, ∪, [U] − [A], [A] − [B], ~ |
| Ⅱ | 합집합의 원소의 개수 (매직) | n( )[A] + n( )[B] − n( )[교집합] |
| Ⅱ | 참·거짓 판별 (매직, ⇄ P⊂Q/Q⊂P) | {x|·}[p] ⊂ {x|·}[q] |
| Ⅱ | 대우 (매직) | [~q] ⇒ [~p] (순서 중요, ~p ⇒ ~q 는 "이") |
| Ⅱ | 필요충분조건 (매직) | [P ⊂ Q] ⋚ [Q ⊂ P] |
| Ⅱ | 드모르간의 법칙 (레어) | ᶜ[합집합] = [Aᶜ] ∩ [Bᶜ] |
| Ⅱ | 절대부등식 (레어) | **[완전제곱 (Ⅰ차원 서고)]** ⋚ [(실수)² ≥ 0] |
| Ⅲ | 대응 (기본) · 함숫값(⇄ a/b) · 일대일대응 | [X] ↦ [Y], [f] ↦ [a], [f(a)] ⋚ [f(b)] |
| Ⅲ | 합성함수 (매직) | [g] ∘ [f] |
| Ⅲ | 역함수 (매직) | 풀기[f] → ⇆ (또는 ⇆ → 풀기) |
| Ⅲ | 역함수의 그래프 (레어) | [역함수] ⟷ **[점의 대칭이동 (Ⅰ차원 서고)]** |
| Ⅲ | 유리함수 · 무리함수 (매직) | [y = k/x] · [y = √(ax)] ↦ **[도형의 평행이동 (Ⅰ차원 서고)]** |

## 시스템 (로드맵 v0.4 · v0.5 · v1.0 미리 보기)

| 시스템 | 테스트판 구현 |
|---|---|
| 갈림길 (v0.5 분기 맵) | 잡몹을 이기면 🎁 보물상자 · 🛒 상인 · ❓ 떠도는 수학자 · 💀 엘리트 중 하나(또는 바로 캠프). 무엇을 골라도 벌은 없음 |
| 보물상자 (주관식) | 문제의 답(정수)을 **다이얼**(부호 + 세 자리)로 맞추면 "철컥" 열리고 유물. 틀려도 다시, 💡 힌트, 그냥 지나가기 가능 |
| 유물 (v0.4) | 착용 칸 3개: 컴퍼스(기력 +1) · 각도기(매 턴 ½칸) · 자(체력 +12) · 돋보기(조각 +1) · 모래시계(첫 턴 +2장) · 계산기(풀이 피해 +6) · 지우개(맞지 않는 도구 기력 0) · 잉크병(턴마다 방어 3). 훈장은 칸을 차지하지 않음 |
| 물약 | 최대 3개, 기력 없이: 회복 · 스캔 · 기력 · 방패. 결계는 못 깸 |
| 기력 2 카드 | 점과 직선 사이의 거리 (풀이로 쓸 때는 항상 기력 1) |
| 기억 결정 ◆ | 전투 보상 → 상점 |
| 매직·레어 연습 문제 | 처음 두 번 공격으로 쓸 때 예제 문제(무작위)를 맞혀야 발동. 틀리면 카드·기력 그대로. 결계 풀이는 해당 없음 |
| 조준 (v1.0) | 답이 점이면 좌표판을 눌러 조준 → 빗나가면 같은 문제를 4지선다로 |
| 숄더뷰 (v1.0, 실험) | 설정에서 켜면 주인공 등 뒤 시점 + 기울어진 홀로그램 좌표판 |
| 몬스터 강화 | 체력 ×1.3 (결계 위치도 같은 비율), 공격 ×1.25 (`DS.Balance`) |
| 진동 · 묶음 보기 | 설정에서 켜고 끔 (묶음 보기 기본 꺼짐 = 낱장) |
